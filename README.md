# Venture eye scale database

How much larger than the requested eye size each Quest game renders. [Venture](https://github.com/Villagers654/Venture) uses it to make games render at the PC VR runtime's resolution.

`titles.json` is keyed by package name. `multiplier` is the rendered eye over the requested one; above 1.1, Venture compensates it.

Entries come from Venture's own test runs and from players' debug reports. Missing or wrong game? Open an issue with a debug report link.
